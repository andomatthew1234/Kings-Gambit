## 🚀 Let's get started

**King's Gambit is now availible on the website. Just go to the site at: https://andomatthew1234.github.io/Kings-Gambit/ to instantly load the latest version.**
You can also run King's Gambit traditionally on your device. Using this method will require manually re-downloading for each new version of King's Gambit. Use this method if the website is down or if the website is blocked. Simply follow these steps:
1. Download the file (Code button > Download .zip).
2. Extract the files by selecting the downloaded .zip in Windows Explorer > Extract all
3. Double click on 'index.html' to run it in your browser! 
After initial setup: Simply double click on the 'index.html' to run it. We suggest adding it to your browser bookmarks so you can access it quickly. 

**Note: Do NOT move the .html file from it's directory. You can move the entire folder, but do not displace the .html folder from the /resources folder, as this may break images and features. If you want to open the file from a differant area, we recomend either moving the entire kingsgambit folder, or creating a shortcut for the .html file.**
