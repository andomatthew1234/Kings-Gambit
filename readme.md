# ♟️ King's Gambit Chess
**An unbloked chess app that runs of your device.**

King's gambit is a chess platform that let's you get straight to the playing.

## King's Gambit features
* 💪 **Chess engine** so you can play against bots that are actually hard to beat.
* 💻 **UI features** smooth, un-buggy UI that actually works.
* 🎓 **For devs, by devs** King's Gambit is fast, runs smoothly, and is fully open-source for anyone to use.
* 📊 **Stats** See your stats in the professional looking way.

## What's new in King's Gambit 2.1?
* 🗃️ **Sidebar** complete actions, and multi-task quickly in the sidebar.
* 🌄 **Customised icons and favicon** a UI that looks and feels good.
* ❌ **Exit match** button to quickly restart the game.
* 📈 **Improved Stats** see more statistics about your game.


## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3

## 🚀 Let's get started
Initial setup:
1. Download the file (Code button > Download .zip).
2. Extract the files by selecting the downloaded .zip in Windows Explorer > Extract all
3. Double click on 'kingsgambit.html' to run it in your browser! 
After initial setup: Simply double click on the 'kingsgambit.html' to run it. We suggest adding it to your browser bookmarks so you can access it quickly. 

**Note: Do NOT move the .html file from it's directory. You can move the entire folder, but do not displace the .html folder from the /resources folder, as this may break images and features. If you want to open the file from a differant area, we recomend either moving the entire kingsgambit folder, or creating a shortcut for the .html file.**
